# Архитектура AI-ОФИСА v0.1

Ядро: Chief of Staff, Project Engine, Task Engine, Specialist Registry, Team Builder, Orchestrator, Verification Engine и Event Bus.

Главный принцип: ядро работает с компетенциями, а не с жёстко заданными профессиями. Специалисты, отделы и команды являются конфигурацией и могут динамически расширяться.

Контур: TASK → IMPLEMENTATION → EVIDENCE → VERIFICATION → PASS/FAIL → NEXT/FIX → RETEST.
